# Врачи и клиники

Каталог из 33 записей: 24 врача и 9 клиник. Поиск по имени, специализации и рекомендации; фильтры по городу, тегу и организации. Имена открывают профили Instagram.

- [Открыть каталог](https://anelime.github.io/doctors-directory/)
- [PDF с кликабельным указателем](doctors.pdf)
- [Исходная подборка в Notion](https://uneven-camelotia-087.notion.site/d9b7594273614478a8bcb36430b82a96)

Данные сохранены 02.10.2026. Сведения, теги и рекомендации перенесены из исходной подборки. Места приёма и актуальность профилей отдельно не проверены. У одной записи ссылка отсутствует. Доступность Instagram зависит от сервиса и сети.

Для использования без интернета скачайте `index.html` и откройте в браузере. Для перехода к внешним профилям нужен интернет.
